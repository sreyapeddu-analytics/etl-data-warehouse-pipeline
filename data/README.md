# Data

All data in this project is **synthetic**, generated by `src/generate_data.py`
with a fixed seed (`random_state=42`) so every run is reproducible. No real
companies, customers, or transactions are involved.

## `raw/` — source-system extracts (intentionally messy)

| File | Rows | Mess injected |
|---|---|---|
| `customers_raw.csv` | 540 | exact duplicates (~8%), null emails/phones/cities, invalid emails (missing `@`/domain), mixed casing, 3 date formats, a few future signup dates |
| `orders_raw.csv` | 2,080 | exact duplicates (~4%), null/negative quantities, null prices, null discounts, discounts > 100%, orphan customer keys (~3%) and product keys (~2%), mixed-case statuses |
| `products_raw.csv` | 63 | exact duplicates (~5%), null costs (~7%), cost > list price (~5%), mixed-case categories |
| `batch2/customers_batch2.csv` | 62 | incremental batch: 30 existing customers with changed city/loyalty tier (drives the SCD Type 2 demo) + 30 new customers |
| `batch2/orders_batch2.csv` | 520 | incremental batch: 500 new orders dated 2025-07-01 → 2025-09-30 |

## Warehouse (`warehouse.db`, repo root)

Built by `python src/run_pipeline.py` from the raw files — **not** committed
(see `.gitignore`). Layers:

- **staging** (`stg_customers`, `stg_orders`, `stg_products`) — 1:1 with the
  source files, minimally conformed; retains quarantined rows (e.g. orphans)
  for audit.
- **dimensions** (`dim_customer` with SCD Type 2 history, `dim_product`,
  `dim_date`) and **fact** (`fact_orders`, one row per order line).

Regenerate everything deterministically:

```bash
python src/generate_data.py
python src/run_pipeline.py
```
